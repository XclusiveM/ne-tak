# НЕ ТАК

Сайт студии «НЕ ТАК». Публичная версия для GitHub Pages.

## Публикация

GitHub Actions workflow `.github/workflows/pages.yml` публикует содержимое ветки `main`. В настройках репозитория выберите **Settings → Pages → Source: GitHub Actions**.

Адрес после успешной публикации: https://xclusivem.github.io/ne-tak/

## Статус

В репозитории размещена облегчённая HTML-версия с калькулятором и брифом. Полный комплект изображений из локальной v13 ещё не перенесён. Отправка заявок на сервер не подключена; бриф можно скопировать. Не публикуйте токены и пароли в репозитории.
