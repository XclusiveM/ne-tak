# План работ и приоритеты

## P0 — до публичного запуска
- [ ] Проверить бренд/товарные знаки и определить домен.
- [ ] Согласовать цену, состав услуг и версионирование прайса.
- [ ] Утвердить юридические тексты, персональные данные и место хранения.
- [ ] Выбрать hosting и создать staging/prod окружения.
- [ ] Создать FastAPI, PostgreSQL, миграции и тестовую среду.
- [ ] Сделать POST lead, server-side estimate, idempotency, outbox.
- [ ] Настроить Telegram-бота студии и повторную доставку.
- [ ] Реализовать защищённую CRM: login, leads, details, statuses, notes.
- [ ] Подключить настоящую форму заявки и проверку ошибок.
- [ ] Добавить наблюдаемость, backup/restore, тесты.
- [ ] Заменить заглушки портфолио на согласованные реальные материалы.
- [ ] QA mobile/desktop/accessibility/performance.

## P1 — после первого потока лидов
- [ ] Контентная админка услуг, кейсов и цен.
- [ ] Шаблоны КП и PDF-экспорт.
- [ ] Задачи и напоминания менеджерам.
- [ ] Email-интеграция и журнал отправки.
- [ ] Аналитика воронки и атрибуция источников.
- [ ] Чат с оператором с историей и SLA.

## P2 — по подтверждённому спросу
- [ ] Клиентский кабинет и проектный трекер.
- [ ] Интеграции платежей и электронных документов.
- [ ] Расширенная автоматизация, ИИ-помощник.
- [ ] Команда исполнителей, рентабельность проектов.

## Definition of Done для каждой задачи
Требование и сценарий описаны; миграции и API документированы; тесты зелёные; доступность и безопасность проверены; staging проверен; логирование и откат предусмотрены; документация обновлена.
